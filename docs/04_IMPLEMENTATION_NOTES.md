## 1. 実装構成

- `index.html`：共通シェル、サイドナビゲーション、店舗選択、モーダル、通知領域
- `assets/css/common.css`：デザイントークン、共通部品、4画面、モーダル、レスポンシブ
- `assets/js/main.js`：架空データ、画面描画、フィルター、発注・入荷フロー、ブラウザ保存
- `assets/images/brand/`：正式ロゴ、シンボル、faviconのSVG
- `assets/images/brand/totte-ogp.png`：GitHub Pages公開用の1200 × 630px OGP画像
- `assets/images/products/`：店舗で撮影した資材の切り抜きを想定した、14品目の背景透過PNGサムネイル
- `404.html`：GitHub Pagesのリポジトリ配下で動作する404ページ
- 商品画像は長辺256px、`object-fit: contain`、隣接する品目名を読み上げるため装飾画像として空の `alt` を使用
- URLのハッシュで `dashboard / sales / inventory / orders` を切り替える1ページ構成
- 保存キー：`totte-demo-state-v2`（正式店舗名・仕入先データへの更新時に切り替え）

外部ライブラリは使わず、HTML / CSS / Vanilla JavaScriptのみで構成している。

商品画像の再制作後、4画面を375 / 390 / 768 / 1024 / 1366 / 1440pxで確認し、画像読み込み失敗、横方向のはみ出し、ブラウザ警告・エラーはいずれも0件だった。

## 4. レスポンシブ方針

- 375 / 390px：1カラム、深いグリーンの上部ヘッダー、下部4画面ナビゲーション、一覧はカード表示
- 768px：深いグリーンの72pxナビゲーションレールと白い上部ヘッダー
- 1024px：深いグリーンの184pxサイドバーと白い上部ヘッダー
- 1366 / 1440px：224pxのサイドバー、多列テーブル、ダッシュボード2領域
- ダッシュボードのモバイル順序は、数値 → 要補充 → 売上推移 → 入荷待ち
- ロゴは1366 / 1440pxで116px幅、1024pxで112px幅のフルロゴ、768pxで22px幅のシンボル、375 / 390pxで92px幅のフルロゴを表示する。
- モバイルヘッダーはシンボル単体ではなく、読みを確認できる白い `totte` 反転ロゴを使用する。
