# totte Decisions Log

更新日：2026-10-11

## 2026-10-11：GitHub Pagesを公開先に採用

### 決定

- 公開先は `https://coconattsu0723.github.io/totte/` を前提とする。
- 1200 × 630pxのOGP画像、canonical、Open Graph、Twitter Card、専用404ページを用意する。
- 404ページは `<base href="/totte/">` を使い、未知の階層から表示されてもリポジトリ直下のCSS・画像・ダッシュボードへ到達できるようにする。

### 理由

- HTML / CSS / Vanilla JavaScriptだけの静的構成で、ビルドやサーバー処理を必要としないため。
- ポートフォリオから共有しやすい固定URLを持ち、作品のソースと公開物を同じリポジトリで管理できるため。
- リポジトリ配下のベースパスを公開前に再現し、相対パスと404の不具合を検証できるため。

## 2026-10-11：中間幅の左ナビゲーションとMobileヘッダーをグリーンへ統一

### 決定

- 375 / 390pxの上部ヘッダー、768pxのナビゲーションレール、1024pxのサイドバーを深いグリーンにする。
- 768 / 1024pxの上部ヘッダーは、1366 / 1440pxと同じ白背景にする。
- 濃色面のロゴは白い反転版を使い、非選択のナビゲーションアイコン・文字も白系で表示する。
- 選択中のナビゲーションは白い面にグリーンのアイコン・文字を組み合わせる。

### 理由

- 1366 / 1440pxのサイドバーと同じブランド面を中間幅の左ナビゲーションとMobileヘッダーへ展開し、画面幅が変わってもtotteらしい識別性を保つため。
- 768px以上のヘッダーは白背景へ統一し、PC系レイアウトの一貫性を保つため。
- 背景とロゴのコントラストを明確にし、白いナビゲーション領域がコンテンツ面と連続して見える状態を避けるため。

## 2026-10-11：画面内ロゴのサイズと背景処理を修正

### 決定

- 反転ロゴと反転シンボルのPencilコンポーネントから背景色を外し、配置先の背景を透かす。
- PCサイドバーのロゴを112px幅へ抑え、キャッチコピーとの間隔を8pxにする。
- 1024pxは112px幅のフルロゴ、768pxは小さなシンボル、375 / 390pxは92px幅のワードマーク付きフルロゴを使用する。

### 理由

- コンポーネントに背景色があると、サイドバーや角丸コンテナとのわずかな色差が四角形として見えるため。
- ロゴとキャッチコピーを分離し、画面幅ごとのナビゲーション密度に合った視覚的な大きさへ揃えるため。
- SPでもシンボルだけでなく名称を読めるようにし、ブランド認知と操作領域のバランスを保つため。

## 2026-10-10：品目サムネイルを正式画像化

### 決定

14品目のピクトグラムを、背景透過の商品サムネイルへ置き換える。実在ブランドは使わず、店舗で実物の資材を撮影して切り抜いたような、無地に近いパッケージと自然な素材感で統一する。資材の横には豆・オーツ・粉などの内容物や演出小物を置かない。

### 理由

- 一覧を文字だけで追わなくても、豆・乳製品・カップ・資材の違いを把握できる。
- 44pxの小さな表示でも、輪郭と素材感によって似た品目を区別しやすい。
- 架空サービスとしての統一感を保ち、第三者ブランドへ依存しない。
- 演出的な商品モックを避け、実店舗の在庫写真へ将来差し替えても違和感の少ない運用にできる。

## 2026-10-10：店舗名と架空業務データを確定

### 決定

- 店舗は「中央通り本店」「北口駅前店」「水辺公園店」の3店舗とする。
- 在庫は14品目を正式な架空データとして使用する。
- 仕入先は「森灯ロースタリー」「朝原デイリー」「風見フーズ」「丸葉パッケージ」の4分類とする。
- 発注番号は `PO-YYYYMMDD-連番`、入荷予定日などの日付は日単位で表示する。

### 理由

- 店舗の立地を短い名称で想像でき、3店舗を切り替えた際にも判別しやすい。
- 仕入先を品目カテゴリに合わせてまとめることで、発注確認時に送り先を確認できる。
- 14品目は、業務画面として一覧性と情報量を示しつつ、デモ操作で見渡せる規模に収まる。

## 2026-10-10：正式ロゴを決定

### 決定

「取っ手」のアーチと小文字の `t` を組み合わせたシンボルに、丸い端部で統一した独自ワードマークを組み合わせる。

### 理由

- 名称の `totte` と、「必要な情報に手が届く」というコンセプトを一つの形で説明できる。
- カフェらしい親しみやすさを保ちながら、業務アプリで必要な落ち着きと信頼感を損なわない。
- 24px程度の小さな表示でも、アーチと縦軸の輪郭を識別できる。
- 既存UIの深いグリーン、丸い端部、控えめな線表現と整合する。

### 正式データ

- Primary：`assets/images/brand/totte-logo-primary.svg`
- Reverse：`assets/images/brand/totte-logo-reverse.svg`
- Symbol Primary：`assets/images/brand/totte-symbol-primary.svg`
- Symbol Reverse：`assets/images/brand/totte-symbol-reverse.svg`
- Favicon：`assets/images/brand/totte-favicon.svg`
- Logo Guide：`design/exports/totte-logo-guide.svg`
- Pencil Guide Preview：`design/exports/totte-logo-guide-pencil.png`
- Pencil Source：`design/pencil/totte-dashboard-desktop.pen`（正式ロゴ4種を再利用可能コンポーネントとして保持）

### 運用

- 白・明るい背景ではPrimary、深いグリーンなど濃色背景ではReverseを使用する。
- キャッチコピー「お店の毎日を、ひとつに整える。」はロゴ本体へ固定せず、別要素として扱う。
- シンボル単体はナビゲーションレール、モバイルヘッダー、faviconなど、横幅が限られる場所で使用する。
